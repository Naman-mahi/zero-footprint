# 📊 Data Feed Schema & Extraction Guide

This document details the structure, properties, and usage of the job datasets generated by our API fetchers:
- **`jobs_all_high_cpc.json`**: 10,000 High-CPC job records (`cpc_value: 0.048` & `sort_by: "high_cpc"`).

- **`jobs_high_cpc.json`**: 8,987 recommendation job records.
- **`jobs_queue.json`**: 8,987 clean recommendation job URLs.

## 📋 Entity Property Reference

Each element in `jobs_all_high_cpc.json` / `jobs_high_cpc.json` contains:

```json
{
  "id": "76628b08-8884-4861-a05e-ce39b626e3dc",
  "title": "Data Scientist",
  "slug": "data-scientist-deloitte-76628b08",
  "company": "Deloitte",
  "location": "Bengaluru, Karnataka, India",
  "cpc_value": 0.048,
  "cpa_value": null,
  "url": "https://my.artha.link/jobs/data-scientist-deloitte-76628b08",
  "apply_url": "https://redirect.artha.link/redirect/...",
  "posted_at": "2026-09-10T12:00:00Z"
}
```

### Property Definitions:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `string (UUID)` | Unique identifier for the job record. |
| `title` | `string` | Job title (e.g. `Senior Data Engineer`). |
| `slug` | `string` | URL-safe slug for the job page path. |
| `company` | `string` | Display name of the hiring employer. |
| `location` | `string` | Formatted geographical location string. |
| `cpc_value` | `number` | Cost-per-click revenue value (e.g. `0.048`). |
| `cpa_value` | `number \| null` | Cost-per-acquisition value (if applicable). |
| `url` | `string (URL)` | Direct job detail URL on portal. |
| `apply_url` | `string (URL)` | Final affiliate tracking redirect URL. |

## 🔄 How the Data is Generated

### 1. High-CPC 10,000 Pipeline (`fetch_all_cpc_pages.js`)
Queries `https://my.artha.link/api/job-api/recommend?pulse_variant=control` with parameters:
- `cpc_value: 0.048`
- `sort_by: "high_cpc"`
- `location: "IN"`
- `limit: 100`

Iterates sequentially across **Pages 1 to 100** (the maximum API depth), deduplicating records by `id` and `url`.

### 2. Standard Recommendation Pipeline (`fetch_recommend_jobs.js`)
Paginates the default recommendation feed to extract all active general openings.
