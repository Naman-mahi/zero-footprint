# 📊 Data Feed Schema & Extraction Guide

This document details the structure, properties, and usage of the job datasets generated by our API fetchers:
- **`jobs.json`**: Complete metadata records of fetched job openings.
- **`jobs_queue.json`**: Deduplicated array of clean application URLs.

---

## 🗂️ Dataset Overview

| File | Type | Record Count | Primary Source |
| :--- | :--- | :--- | :--- |
| [`jobs.json`](file:///d:/DEVELOPMENT/all-bots/jobs.json) | Metadata Array | **2,000+** | `fetch_recommend_jobs.js` |
| [`jobs_queue.json`](file:///d:/DEVELOPMENT/all-bots/jobs_queue.json) | URL Array | **2,000+** | Clean deduplicated apply URLs |

## 📋 Entity Property Reference

Each element in `jobs.json` contains:

```json
{
  "id": "0006f93d-d277-4451-941a-00a540c1fa22",
  "title": "Software Engineer",
  "slug": "software-engineer-micro1-79ebd89a",
  "company_name": "micro1",
  "apply_link": "https://artha.link/@eanxt/jobs/software-engineer-micro1-79ebd89a",
  "country": "IN",
  "city": "Bengaluru",
  "job_type": "full-time",
  "work_mode": "remote",
  "salary_min": null,
  "salary_max": null,
  "salary_curr": null,
  "posted_date": "2026-08-21T14:04:15"
}
```

### Property Definitions:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | `string (UUID)` | Unique identifier for the job record. |
| `title` | `string` | Job title (e.g. `Software Engineer`). |
| `slug` | `string` | URL-safe slug for the job page path. |
| `company_name` | `string` | Name of the hiring employer. |
| `apply_link` | `string (URL)` | Direct application page URL. |
| `country` | `string` | ISO country code (e.g. `IN`, `US`). |
| `city` | `string \| null` | City location if available. |
| `job_type` | `string \| null` | Employment type (`full-time`, `contract`, `internship`). |
| `work_mode` | `string \| null` | Work environment (`remote`, `on-site`, `hybrid`). |
| `posted_date` | `string \| null` | ISO timestamp of job posting date. |

## 🔄 How the Data is Generated

### Recommendation Pipeline (`fetch_recommend_jobs.js`)
Paginates through active job recommendations directly from the Artha recommendation API endpoint without artificial filtering:
```powershell
node fetch_recommend_jobs.js 20 100 IN
```
Generates `jobs.json` with full rich metadata and `jobs_queue.json` containing ready-to-run application URLs.
